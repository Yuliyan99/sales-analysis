Анализ на продажби
Конзолно приложение, което чете sales.csv и анализира продажбите по зададен филтър и/или категория от потребителя

Инсталация: pip install -r requirements.txt
Стартиране: python main.py

Библиотеки: matplotlib (грифики), csv (вградена).
Менюто позволява: общ приход, приход по категории, филтриране, топ продукти, графика.
