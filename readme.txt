Анализ на продажби (версия 2)
Конзолно приложение, което чете всички CSV файлове от папка data и анализира
продажбите за избран месец или период.

Инсталация:  pip install -r requirements.txt
Стартиране:  python main.py

Как се ползва:
1. Сложете месечните CSV файлове в папка data (имената им нямат значение).
   Колоните са: date,product,category,quantity,price. Датата е във вид 2026-01-05.
2. При старт въведете месец (2026-01) или период (2026-01 2026-03).
   Enter без текст означава всички данни.
3. От менюто изберете: общ приход, приход по категории, филтър по категория,
   топ продукти, графика, смяна на период.
Невалидните редове във файловете се пропускат със съобщение.
Не бива един и същ месец да е в два файла, защото продажбите ще се броят два пъти.

Библиотеки: matplotlib (графики); csv, datetime, pathlib (вградени).
Валута: EUR.
